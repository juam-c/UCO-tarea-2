# Habilidad de Explicación de Código
Al explicar código al usuario:
1. Divide la explicación en: Propósito general, Flujo de datos y Puntos críticos.
2. Usa analogías sencillas si el algoritmo es complejo.
3. Si el código tiene un riesgo potencial de seguridad o cuello de botella, añade una sección de "Advertencia".
