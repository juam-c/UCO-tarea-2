# Habilidad de Optimización
Cuando optimices código en este repositorio:
1. Prioriza la reducción de la complejidad ciclomática.
2. Evita la duplicación de funciones de utilidad compartidas.
3. Asegúrate de mantener la retrocompatibilidad con las funciones existentes.
4. Muestra un "Antes y Después" en formato de bloque de código junto con el impacto en el rendimiento estimado.
