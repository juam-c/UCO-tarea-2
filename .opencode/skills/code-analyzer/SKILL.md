# Habilidad de Análisis de Código
Al activar esta habilidad, debes:
1. Usar `grep` o `read` para mapear las dependencias del proyecto.
2. Identificar el patrón de diseño utilizado (MVC, Clean Architecture, etc.).
3. Generar un diagnóstico antes de sugerir cualquier cambio. No asumas código que no has leído.
