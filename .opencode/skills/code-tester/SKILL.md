# Habilidad de Testing (Enfoque Red-Green-Refactor)
1. Cada vez que edites un archivo, debes correr el comando de testing del proyecto usando la herramienta `bash`.
2. Si el proyecto usa Node.js, ejecuta `npm run test`. Si usa Python, ejecuta `pytest`.
3. No des una tarea por finalizada hasta que la terminal devuelva un estado exitoso (Exit Code 0).
